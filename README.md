# ROMA — Перекрёстки Республики

Русскоязычный атлас Суллы, Юлия Цезаря, Марка Лициния Красса и Гнея Помпея Великого.

[Открыть приложение](https://evgk724.github.io/roma-atlas/)

Вертикальная лента четырёх биографий связана общей шкалой времени, событиями, источниками и карточками для повторения. Крупный текст имеет три размера. Возраст на шкале приблизительный; в биографиях отдельно поясняются спорные даты и количество полных лет. Античные сообщения о здоровье отделены от современных ретроспективных гипотез.

Нажатие стрелки у верхнего или нижнего края прокручивает часть экрана, удержание — плавно ведёт текст. Включаемый режим мыши запускает прокрутку при наведении на край и останавливает при уходе. Удержание Space/Enter на стрелке также работает. Выход из окна, скрытие страницы и открытие диалога останавливают движение. Обычные жесты прокрутки сохраняются.

История повторения сохраняется только после отметки пользователя в localStorage. «Ещё раз» — 10 минут; «Вспомнил» — 1, 3, 7, 14, 30 дней. Синхронизации между устройствами нет. Активная тренировка защищена от автообновления, в том числе во время чтения биографии. При запрете хранения показывается уведомление, история остаётся в памяти страницы, обновление откладывается.

## Сборка

```sh
python3 scripts/build.py
python3 -m http.server 8772 --directory docs
```

Источники и данные — `content.json`, оформление и логика — `src/`, оригинальная векторная графика — `docs/assets/`. Портреты являются художественными реконструкциями, а не точными копиями древних бюстов. QR и готовые PNG уже включены. Для повторной генерации иконок нужен Node.js с Playwright, для QR — Python с ReportLab/Pillow.

```sh
node tests/learning.cjs
node tests/browser.cjs
```

`PLAYWRIGHT_MODULE` позволяет указать установленный Playwright, `BASE_URL` — адрес сайта, `QA_OUTPUT` — файл отчёта. GitHub Pages публикует `main:/docs`. Онлайн-версия проверяет `version.json` при открытии, возвращении к странице и раз в минуту. `docs/ROMA.html` — автономный файл со встроенной графикой, текстом и тренировкой; внешние источники требуют сети.
